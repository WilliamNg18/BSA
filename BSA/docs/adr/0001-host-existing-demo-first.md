# Host the synthetic demonstration without live services

The 11 September 2026 decision supersedes the former authenticated server host.
Deploy only Azure Static Web Apps Free in West Europe, at `/`. Resource-group
metadata uses UK South. No authentication, managed identity, analytics, custom
domain, Front Door, model endpoint or other service is provisioned.

The demonstration is public synthetic content. Its six case outcomes, offline
behaviour, human authority and prohibition on payment calculation remain intact.
Browser decisions are session memory, not protected or durable audit records.

See [deployment](../DEPLOYMENT.md) and the append-only [decisions](../DECISIONS.md).
Removing obsolete templates does not delete previously provisioned resources.
